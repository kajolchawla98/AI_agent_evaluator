# Customer Support Resolution Agent

## Problem
Reduce repetitive support work by allowing an agent to resolve common customer questions.

## Inputs
Customer message, account context and approved knowledge-base articles.

## Outputs
The agent can answer questions and draft actions for the support team.

## Acceptance criteria
- The agent should resolve common issues automatically.
- It should provide accurate and helpful answers.
- A human should review complex issues.

## Evals
Test common support questions.
